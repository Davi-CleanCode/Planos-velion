# Comercial Velion

Projeto frontend em TypeScript, com Vite.

## Estrutura

- `index.html` — estrutura e conteúdo da apresentação
- `src/styles.css` — estilos
- `src/main.ts` — comportamento TypeScript
- `public/llms.txt` — informações para sistemas de IA/LLMs
- `public/robots.txt` — regras básicas de rastreamento
- `vite.config.ts` — configuração do Vite
- `tsconfig.json` — configuração TypeScript

## Backend

Não há backend Node neste projeto. O projeto é frontend estático.

O Node.js aparece apenas como ferramenta de desenvolvimento/build do Vite (não como servidor de aplicação).

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```
